# Security policy

We take the security of StackWise projects, and of the products we build for clients, seriously.

## Reporting a vulnerability

**Please do not report security problems in public issues, pull requests or discussions.**

Report them privately in one of these ways:

- Use **"Report a vulnerability"** on the affected repository's **Security** tab, where it is enabled.
- Or email **stackwiseind@gmail.com** with "Security" in the subject line.

Please include:

- the repository, URL or product affected
- what the problem is and what an attacker could do with it
- steps to reproduce it, or a proof of concept
- any suggested fix, if you have one

We will acknowledge your report, keep you updated while we investigate and fix it, and credit you when the fix is released unless you would rather stay anonymous.

## Scope

This policy covers the code in the StackWise GitHub organization and the StackWise website. Products we have built for clients are owned by those clients; if you find a problem in one, email us and we will pass it to the right people.

Please do not run tests that could harm users or their data, such as denial-of-service attacks, spam or social engineering.
