# Getting help

- **A bug or a question about one of our open-source projects:** open an issue in that repository.
- **A security problem:** follow our [security policy](SECURITY.md). Please do not use a public issue.
- **A new project, a quote or work with StackWise:** use the form at [stackwise.yashsuthar.dev/contact](https://stackwise.yashsuthar.dev/contact) or email **stackwiseind@gmail.com**.
- **Support for a product we built for you:** email us at **stackwiseind@gmail.com**, or use the channel agreed in your support plan.
