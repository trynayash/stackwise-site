# StackWise

The website for StackWise, Yash Suthar's software studio. It is a single-page marketing site with service pages, a portfolio with project write-ups, pricing, an FAQ and a contact form.

Live site: https://stackwise-gamma.vercel.app

## What is in it

- Home page sections in `src/components/sections/` (hero, services, process, portfolio, pricing, FAQ, founder, tech stack, contact)
- Service and solution pages under `src/app/services/` and `src/app/solutions/`
- Project write-ups at `/work/[slug]`, built from the data in `src/lib/data.ts`
- A contact API at `src/app/api/contact/route.ts` that validates input with Zod and has a simple in-memory rate limit
- Security headers (CSP, HSTS, frame options) set in `src/middleware.ts`
- Sitemap and robots files generated by Next.js
- Animations with Framer Motion and GSAP, and a custom display font (Oughter)

## Tech stack

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, Framer Motion, GSAP, Lucide icons, Zod.

## Run it locally

You need Node.js 20 or newer.

```bash
git clone https://github.com/trynayash/stackwise-site.git
cd stackwise-site
npm install
npm run dev
```

Open http://localhost:3000.

Production build:

```bash
npm run build
npm start
```

## Project structure

```
public/            Images, logos, fonts and icons
src/app/           Pages, API route, sitemap and robots
src/components/    Layout, page sections, inquiry form and UI pieces
src/config/        Site settings, pricing and principles
src/lib/           Portfolio data, SEO helpers and utilities
```
