# StackWise

The website for StackWise, Yash Suthar's software studio in Mumbai. It is a single-page marketing site with service pages, a portfolio with project write-ups, pricing, an FAQ and a contact form.

Live site: https://stackwise-site.vercel.app (Vercel project `stackwise-site`; every push to `main` deploys to production)

## What is in it

- Home page sections in `src/components/sections/` (3D hero, services, selected work, capabilities, process, comparison, pricing, principles, founder, technology, FAQ, CTA, contact)
- Shared UI in `src/components/ui/`: `Button`/`ButtonLink`, `Card`, `Icon` (Hugeicons), form fields, FAQ accordion and motion helpers. Colours are tokens in `src/app/globals.css` (`bg-canvas`, `bg-surface`, `border-line`, `text-accent`, …)
- Desktop navigation with a Services mega menu, and a full-screen mobile menu
- Interactive 3D hero model in `src/components/three/` (three.js via React Three Fiber, lazy-loaded, with a CSS fallback for reduced motion or no WebGL)
- Service and solution pages under `src/app/services/` and `src/app/solutions/`, all rendered by one template (`src/components/marketing/`) from the content in `src/lib/marketing-pages.ts`
- Generated social-share images at `/og?title=...&kicker=...`, and JSON-LD (Organization, Service, FAQ, Breadcrumb) via `src/lib/schema.tsx`
- Case studies at `/work` and `/work/[slug]`. The three featured ones come from `src/lib/case-studies.ts`. That file is copied from the yashsuthar.dev portfolio (`src/config/case-studies.ts`) so both sites describe the work the same way; smaller projects live in `src/lib/more-work.ts`; screenshots are in `public/projects/`
- A contact API at `src/app/api/contact/route.ts` that validates input with Zod and has a simple in-memory rate limit
- Security headers (CSP, HSTS, frame options) set in `src/middleware.ts`
- Sitemap and robots files generated by Next.js
- Animations with Framer Motion: pinned horizontal case-study showcase, scroll-lit text, stacking process cards, wipe-in screenshots, count-ups and rolling button labels (all respect reduced motion), plus a custom display font (Oughter) for the wordmark
- Technology logos are self-hosted white SVGs from Simple Icons (CC0) in `public/logos/tech/`

## Tech stack

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, Framer Motion, GSAP, three.js / React Three Fiber, Hugeicons, Zod.

## Run it locally

You need Node.js 20 or newer.

```bash
git clone https://github.com/trynayash/stackwise-site.git
cd stackwise-site
npm install
npm run dev
```

Open http://localhost:3000.

Production build:

```bash
npm run build
npm start
```

## Project structure

```
public/            Images, logos, fonts and icons
src/app/           Pages, API route, sitemap and robots
src/components/    Layout, page sections, inquiry form and UI pieces
src/config/        Site settings, pricing and principles
src/lib/           Portfolio data, SEO helpers and utilities
```
